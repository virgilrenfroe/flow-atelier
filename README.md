# Flow atelier

Music-driven flow field — *A Song with a Hole in It* (Virgil Renfroe).

Live: https://virgilrenfroe.github.io/flow-atelier/

Click **Song** (or `A`) to unlock audio. Opens on the four-corner mirror (one sim, four flips, trails bleed across the center). Modes: mirror · mask · pack · curl · attrib · wrap · music. SVG export with `E`.
